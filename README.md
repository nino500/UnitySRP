# Unity SRP

a Unity simple SRP following the  Catlike Coding Custom SRP tutorials.

# Implemented Features


## LOD
- Clip-based Fade LOD support 

## Lighting and Materials
- Custom render pipeline and camera rendering
- Multiple directional light
- BRDF lighting model (metallic-flow)
- Baked lighting support(lightmap,light probe,LPPV,reflection probe)

## shadow

- Real-time directional shadows
- Shadow Bias
- Cascade shadow maps 
- PCF Filtering option
- Smooth Transition

- Baked directional shadows support for multiple lights

## Editor
- Material Property Presets
